# Spesa

Web app personale per analizzare gli acquisti alimentari.

## Stack
- HTML/CSS/JavaScript
- Supabase Auth + PostgreSQL
- Tesseract.js per OCR locale nel browser
- GitHub Pages

## URL GitHub Pages
Dopo la pubblicazione del repository, l'app è disponibile nella sottocartella `/spesa/`.

## Funzioni MVP
- Login Supabase
- Importazione foto scontrino
- OCR in italiano
- Revisione prima del salvataggio
- Categorie, marche e supermercati
- Distinzione alimentare/non alimentare
- Ignora sconti
- Storico spese
- Analisi prodotti
- Budget mensile
- Previsione riacquisti basata sullo storico
